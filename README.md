# Compression-Aware Audio Deepfake Detection

This project detects synthetic speech in low-resource languages (Sinhala and Tamil) under realistic compression conditions.

## Project Structure
* `data/`: Contains real, fake, and compressed audio datasets.
* `src/`: Core source code for data processing and models.
* `docs/`: Project documentation and scope.
* `weights/`: Saved model checkpoints.
* `notebooks/`: Jupyter notebooks for EDA and evaluation.
